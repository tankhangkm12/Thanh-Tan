# design-core

Core của nhóm **design-system**. Giữ workflow G0–G10, 8 tiêu chí chất lượng, bảng quyền của agent, 5 agent và 5 góc nhìn hội đồng (`claude/agents/`, định dạng Claude Code), template workspace và script `init_workspace.py`; các plugin `design-*` khác dùng lại. Kiểm agent: `uv run --with pytest --with pyyaml pytest core/scripts`. Hiện xong Giai đoạn 1 và 2; script kiểm tra ở Giai đoạn 3. Xem [PLAN.md](../PLAN.md).
