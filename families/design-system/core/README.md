# design-core

Core của nhóm **design-system**. Giữ workflow G0–G10, 8 tiêu chí chất lượng, bảng quyền của agent, 5 agent và 5 góc nhìn hội đồng (`claude/agents/`, định dạng Claude Code), template workspace, script (`scripts/`: `init_workspace`, `detect_models`, `guard_write` + `hooks/hooks.json`, `calc_capacity`, `check_links`, `check_profile`, `check_numbers`, `check_versions`) và dữ liệu cấu hình của script (`data/`); các plugin `design-*` khác dùng lại. Chạy test: `uv run --with pytest --with pyyaml pytest core/scripts`. Hiện xong Giai đoạn 1, 2 và 3A; còn script Giai đoạn 3B (`tally_votes`, `check_trace`, `check_workspace`, `promote_drafts`, `archive_release`, `call_council_cli`). Xem [PLAN.md](../PLAN.md).
